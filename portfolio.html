Projects

Online Food Delivery System

The Online Food Delivery System is a full-stack web application designed to connect customers, food partners, and delivery drivers. The application allows users to browse food, manage their basket, place orders, and track order progress.

The project uses React and TypeScript on the frontend and Node.js, Express.js, and MongoDB on the backend. It also includes authentication, role-based functionality, REST APIs, image uploads, and order-management features.

Technologies: React, TypeScript, Tailwind CSS, Node.js, Express.js, MongoDB, Axios, REST API, Git, and GitHub.

College Management Learning Management System

The College Management Learning Management System is a web application designed to manage college-related information and administrative processes. The system is planned around different administrative roles and college management features.

The project includes functionality for college administration, departments, programs, academic years, batches, semesters, students, admissions, scholarships, and financial information.

Technologies: React, Node.js, Express.js, MySQL, Sequelize, JavaScript, TypeScript, REST APIs, Git, and GitHub.
